## 섹션 1. 개발 목적과 배경

### 슬라이드 1: 표지
- **핵심 메시지**: "그 동네는 원래 그 정도"를 **계산식**으로
- **본문 내용**:
  * **부제**: 개발 목적 · 히스토리 v1~v3 · 조사 검증 · 로드맵
  * **발표자**: Yudev / 2026년 11월
- **시각화 가이드**: 다크 배경 전면, 좌측 상단 `PROJECT REVIEW` 배지, 틸 포인트 컬러

### 슬라이드 2: 문제 정의
- **핵심 메시지**: **가장 큰 금액**이 걸린 결정을, **가장 경험 없는 상태**에서 내린다
- **본문 내용**:
  * **① 제시**: 중개사가 권리금 **3억** 제시
  * **② 판단 불가**: 비싼지 싼지 가늠할 **기준 없음**
  * **③ 감으로 회신**: "그 동네는 원래 그 정도"
  * **④ 근거 부재**: 그 '몇 개월치'를 **아무도 설명 못 함**
- **시각화 가이드**: 4단 프로세스 카드(번호 원형 아이콘), 하단에 앰버 강조 박스 — "업계의 감은 틀린 게 아니라, **검증도 전수도 안 된다**"

### 슬라이드 3: 왜 일반 계산기로는 안 되는가
- **핵심 메시지**: 약국은 **권리금 구성 요소 자체**가 다르다
- **본문 내용**:
  * **수익 원천**: 매출 전체 ↔ **조제료(처방)**
  * **수요 성격**: 유동인구 ↔ **인근 병·의원 처방 종속**
  * **입지**: 이전 가능 ↔ **병원 앞 자리 대체 불가**
  * **리스크**: 상권 쇠퇴 ↔ **병원 이전·폐업 시 수익 소멸**
  * **시설·재고**: 범용 ↔ **조제 전용 설비 · 유효기간 리스크**
- **시각화 가이드**: 2열 비교표(일반 상가 vs 약국), 하단 틸 결론 박스 — "소형 과대평가 · 문전 대형 과소평가"

### 슬라이드 4: 해결 접근
- **핵심 메시지**: 감을 부정하지 않고, **감이 담은 판단을 수식으로** 옮긴다
- **본문 내용**:
  * **공식**: 월 환산수익 × **지역 회수개월수** × **조제료 규모 계수**
  * **월 환산수익**: 조제 수익 + OTC 마진 − 월세 − 보증금 기회비용
  * **결과 형태**: 단일 금액 아님 → **최소(빠른 매도) ~ 최대(높은 호가) 범위**
  * **범위 내 위치**: 임대차·처방 추이·매도 시급성 **체크리스트로 좁힘**
- **시각화 가이드**: 중앙 대형 공식 카드 3블록(곱셈 기호로 연결), 하단 범위 바(최소~최대 그라데이션)

## 섹션 2. 개발 히스토리

### 슬라이드 5: 전체 흐름
- **핵심 메시지**: **정답지 → 계산식 → 보정 → 확장** 순서로 만들었다
- **본문 내용**:
  * **0단계**: 현장의 감을 숫자로 — 20케이스 조사, 오차 측정
  * **v1**: 회수배수 계산식 — 경계에서 금액 **2배 점프**
  * **v2**: 절벽 완만화 — 기준점 보존 **선형보간**
  * **v3**: 외부 데이터 결합 — 공공데이터·카카오·**Gemini**
  * **상시화**: 설문 → DB 적재 → **계수 자동 보정**
- **시각화 가이드**: 세로 타임라인 5단, 단계별 컬러(회색→앰버→틸→그린→남색), 각 단에 한 줄 결과

### 슬라이드 6: 0단계 — 계산식보다 정답지를 먼저
- **핵심 메시지**: 식을 먼저 만들면 **검증할 방법이 영영 생기지 않는다**
- **본문 내용**:
  * **설계**: 가상 **20케이스** = 지역 5권역 × 규모별, 조건은 랜덤·반올림
  * **의도적 공개**: 모델 산출가를 **숨기지 않고 함께 제시**
  * **목적**: 정답 수집이 아니라 **오차 측정**
  * **표본**: 1차 2명 **40응답**(모델 선택) → 2차 3명 **60응답**(계수 보정)
- **시각화 가이드**: 실제 조사지 표 발췌(케이스 2·7·9·14·17), 마지막 열 "내가 보는 적정 권리금"은 빈칸으로 강조

### 슬라이드 7: 0단계 결과 — 모델 선택
- **핵심 메시지**: 일반 상가식은 **평균이 아니라 구조**가 틀렸다
- **본문 내용**:
  * **모델 A** (매출총이익 × 12개월): 범위 적중 **7/40 (18%)**
  * **모델 B** (회수배수 × 규모 계수): 범위 적중 **32/40 (80%)**
  * **편향 — 소형**: 응답 대비 **3.03배 과대** (1.59~4.16배)
  * **편향 — 일반**: 응답 대비 **0.67배 과소** (0.46~1.15배)
  * **결론**: 한쪽은 3배 높고 한쪽은 1/3 낮음 → **어떤 배수로도 동시에 못 맞춤**
- **시각화 가이드**: 좌측 막대 차트(적중률 7 vs 32), 우측 편향 수치 카드 2장(과대 빨강 / 과소 파랑)

### 슬라이드 8: v1 — 계산식
- **핵심 메시지**: 살아남은 구조를 **5단계 식**으로 구현
- **본문 내용**:
  * **① 월 환산수익**: 조제 수익 + OTC 마진 − (월세 + 보증금 기회비용)
  * **② 규모 계수**: 조제료 5구간 **고정값** (0.50 / 1.00 / 1.15 / 1.25 / 1.35)
  * **③ 3단계 가격**: 지역 **p30 / p50 / p75** 회수개월수 + 저수익 임계 할인
  * **④ 의사 고령**: 65세 **×0.7** · 75세 **×0.5**
  * **⑤ 보정**: 지역 피드백 ±10% · 설문 ±15%
- **시각화 가이드**: 좌측 5단계 번호 리스트, 우측 지역 회수개월수 표(5개 권역 × p30/p50/p75)

### 슬라이드 9: v1 검증 — 60응답으로 보정
- **핵심 메시지**: 두 군데만 고쳐 적중률 **68% → 85%**
- **본문 내용**:
  * **발견 ①**: 조제료 1,000만원 이상 17케이스 — 모델이 **15% 낮음** (1.156)
  * **발견 ②**: 1,000만원 미만 3케이스 — 모델이 **35% 높음** (0.647)
  * **조치**: 전 지역 회수개월수 **×1.15** · 소형 계수 **0.88 → 0.50**
  * **결과**: 적중 41/60 → **51/60**, ratio 중앙값 1.129 → **0.999**
  * **조사원 3**: 9/20 → **18/20** (높게 보는 성향이 보정으로 흡수)
- **시각화 가이드**: 보정 전/후 그룹 막대 차트(전체·소형·일반 ratio, 기준선 1.0 표시) + 조사원별 before/after 표

### 슬라이드 10: v1 문제 — 절벽
- **핵심 메시지**: 조제료 **1만원** 차이로 권리금이 **2배**가 된다
- **본문 내용**:
  * **999만원**: 계수 0.50 → **9,118만원 ~ 1.49억원**
  * **1,000만원**: 계수 1.00 → **1.83억원 ~ 2.99억원**
  * **경계별 점프**: 1,000만원 **+100%** / 2,500만원 +15% / 3,500만원 +9% / 5,000만원 +8%
  * **본질**: 구간을 나눈 **편의가 결과의 왜곡**으로 — 쓰는 사람에게는 **신뢰 문제**
- **시각화 가이드**: 실제 화면 캡처 2단 비교 이미지(999 vs 1,000), 상단에 빨강 점프 지표

### 슬라이드 11: v2 — 완만화 방법 선택
- **핵심 메시지**: 5개 계수는 **검증된 자산** — 바꿀 것은 "구간 안에서 계수가 고정"이라는 가정뿐
- **본문 내용**:
  * **안 1 — 구간 세분화**: 절벽이 작아질 뿐 **소멸 안 함**, 계수표 4배
  * **안 2 — 회귀 적합**: 검증값 소멸 + 20케이스로 곡선 추정은 **과적합**
  * **안 3 — 기준점 보존 보간**: 검증 결과 **100% 보존** → **채택**
  * **재해석**: 5개 값 = 구간 대표값 → **1,000/2,500/3,500/5,000만원 지점의 기준점**
- **시각화 가이드**: 3개 안 비교표(채택 행만 틸 하이라이트), 하단에 lerp 수식 코드 박스

### 슬라이드 12: v2 — 결과 곡선
- **핵심 메시지**: 기준점에서 **만나고**, 사이에서만 달라진다
- **본문 내용**:
  * **경계 점프**: +100% → **+0.05%** (1,000만원 지점)
  * **나머지 경계**: +15/+9/+8% → **모두 +0.01% 이하**
  * **동일 조건 999만원**: v1 9,118만원 → v2 **1.82억원** (1,000만원일 때와 사실상 동일)
  * **불변 조건**: 지역 회수개월수 · 저수익 할인 · 고령 할인 · 보정 **그대로**
- **시각화 가이드**: 계수 곡선 비교 그래프(v1 계단 앰버 / v2 곡선 틸, 1,000만원 지점 빨강 수직선) 전면 배치

### 슬라이드 13: v2 검증 — 반전
- **핵심 메시지**: **매끄러운 식이 정확한 식은 아니었다**
- **본문 내용**:
  * **v1 계단형**: 적중 **51/60 (85%)** · 소형 **0.992** · 일반 1.006
  * **v2 곡선형**: 적중 42/60 (70%) · 소형 **0.525** · 일반 0.943
  * **원인**: v2는 0→1,000만원 직선 보간 → 조제료 800만원에 계수 **0.90**
  * **충돌**: v1의 **0.50은 소형 응답으로 직접 보정한 값**
  * **판단**: 소형 표본 3케이스 9응답 → 결론 불가 → **v1 기본값 유지**, v2는 비교용
- **시각화 가이드**: 구간별 ratio 그룹 막대(기준선 1.0, 소형 구간 격차를 빨강으로), 하단 결론 박스 — "검증 데이터가 있었기에 배포 전에 알았다"

### 슬라이드 14: v3 — 입력할 수 없는 데이터
- **핵심 메시지**: 핵심 변수는 **사용자가 모르는 정보**였다
- **본문 내용**:
  * **적용**: 병·의원 수 · 약국 수 · 반경 500m 상권 · 주소→좌표 · 우편번호
  * **판정 기준**: 약국 1곳당 병·의원 수를 **전국 평균 1.7곳**과 비교 (3단계)
  * **미적용**: 처방·청구 통계 — **약국 단위 공개 데이터 없음**
  * **부재**: 권리금 **실거래 DB 자체가 존재하지 않음**
  * **원칙**: 키 없으면 해당 블록만 '미조회' — **계산은 정상 동작**
- **시각화 가이드**: 데이터 소스 표(적용/미적용 색 구분), 우측에 1.7:1 기준 3단계 판정 카드

### 슬라이드 15: v3 — 화면
- **핵심 메시지**: 실측으로 **사용자 입력까지 검증**한다
- **본문 내용**:
  * **실측**: 강남구 병·의원 **3,119곳** / 약국 **515곳** = **6.1:1** (평균의 3.6배)
  * **입력 검증**: 사용자 선택 '동네/주택가' → 실제 입지와 **불일치 지적**
  * **금액 연결**: 수정 반영 시 조정 합계 +10% → **+15%**, 범위 4.07~6.68억 → **4.25~6.99억**
  * **매물 조정**: 상권 · 병원 의존도 · 잔여 임대차 · 임대료 부담
- **시각화 가이드**: v3 리포트 화면 캡처를 좌측 2/3, 우측에 수치 하이라이트 카드 3장

### 슬라이드 16: v3 — AI는 계산하지 않는다
- **핵심 메시지**: **말로 부탁한 건 깨지고, 구조로 막은 것만 남았다**
- **본문 내용**:
  * **원칙**: 수치는 PHP가 확정 → AI는 **서술만** (`temperature: 0`)
  * **실패 ①**: 금액이 매번 다름 → **재계산 금지 명시** + 확정치 주입
  * **실패 ②**: 자유 서술로 회신 → **responseSchema 8필드 강제**
  * **실패 ③**: 범위를 단일 금액으로 단정 → 수치 아래 **범위 기준 지시**
  * **실패 ④**: 검증이 "타당합니다"로 종료 → **목록에서 그대로 반환** + 금액 재계산 표시
  * **실패 ⑤·⑥**: 토큰 잘림 → 상한 설정 / 고령 **이중 할인** → 엔진 단일화
- **시각화 가이드**: 좌측 프롬프트 코드 박스(첫 3줄 발췌), 우측 실패→해결 6행 표

### 슬라이드 17: v1 ~ v3 종합 비교
- **핵심 메시지**: 기초 산출은 **하나의 엔진**, 쓰임만 다르다
- **본문 내용**:
  * **기초 산출**: v1 = v3 **동일 엔진**(`gwBaseQuote`) / v2는 계수 함수만 교체
  * **60응답 적중**: v1 **51/60** · v2 42/60 · v3 v1과 동일
  * **입력 변수**: 5개 · 5개 · **15개+**
  * **외부 데이터**: 없음 · 없음 · **병·의원 · 약국 · 상권 · AI**
  * **용도**: **기본 시세** · 경계 비교 · **매물 실사·협상 준비**
- **시각화 가이드**: 3열 비교표(v3 열 강조), 하단에 v3 검증 4축(기초 일치 · 재현성 · 실측 · 장애 내성) 배지

## 섹션 3. 데이터와 API

### 슬라이드 18: 조사 원자료와 재현성
- **핵심 메시지**: 발표의 모든 수치는 **원자료에서 다시 계산된다**
- **본문 내용**:
  * **원자료**: 20케이스 × 조사원 3명 = **60응답** CSV (2026-09)
  * **기록 항목**: 지역 · 조제료 · OTC · 월세 · 보증금 · **모델 3단계가** · 조사원 응답
  * **재현**: `php doc/data/verify-model.php` → 보정 전/후 × v1/v2 **4개 조합 일괄 출력**
  * **검증 지표**: 범위 적중 · ratio 중앙값(전체/소형/일반) · 케이스별 · 조사원별
- **시각화 가이드**: 좌측 CSV 구조 표, 우측 터미널 출력 캡처 스타일 박스(4줄 결과)

### 슬라이드 19: 사용한 API와 키 발급
- **핵심 메시지**: **무료 공개 API 3종**, 키가 없어도 계산은 돈다
- **본문 내용**:
