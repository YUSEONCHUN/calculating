## 섹션 1. 개발 목적과 배경

### 슬라이드 1: 표지
- **핵심 메시지**: "그 동네는 원래 그 정도"를 **계산식**으로
- **본문 내용**:
  * **부제**: 개발 목적 · 만든 과정 1~3차 · 조사로 검증한 결과 · 앞으로의 계획
  * **발표자**: Yudev / 2026년 11월
- **시각화 가이드**: 다크 배경 전면, 좌측 상단 `PROJECT REVIEW` 배지, 틸 포인트 컬러

### 슬라이드 2: 문제 정의
- **핵심 메시지**: **가장 큰 금액**이 걸린 결정을, **가장 경험 없는 상태**에서 내린다
- **본문 내용**:
  * **① 제시**: 중개사가 권리금 **3억** 제시
  * **② 판단 불가**: 비싼지 싼지 가늠할 **기준 없음**
  * **③ 감으로 회신**: "그 동네는 원래 그 정도"
  * **④ 근거 부재**: 그 '몇 개월치'를 **아무도 설명 못 함**
- **시각화 가이드**: 4단 프로세스 카드(번호 원형 아이콘), 하단 앰버 강조 박스 — "감은 틀린 게 아니라 **검증도 전수도 안 된다**"

### 슬라이드 3: 왜 일반 계산기로는 안 되는가
- **핵심 메시지**: 약국은 **권리금 구성 요소 자체**가 다르다
- **본문 내용**:
  * **수익 원천**: 매출 전체 ↔ **조제료(처방)**
  * **수요 성격**: 유동인구 ↔ **인근 병·의원 처방 종속**
  * **입지**: 이전 가능 ↔ **병원 앞 자리 대체 불가**
  * **리스크**: 상권 쇠퇴 ↔ **병원 이전·폐업 시 수익 소멸**
  * **시설·재고**: 범용 ↔ **조제 자동화기기 · 유효기간 리스크**
- **시각화 가이드**: 2열 비교표, 하단 틸 결론 박스 — "소형 과대평가 · 문전 대형 과소평가"

### 슬라이드 4: 해결 접근
- **핵심 메시지**: 감을 부정하지 않고, **감이 담은 판단을 수식으로** 옮긴다
- **본문 내용**:
  * **한 달에 남는 돈**: 조제 수익 + 일반약 마진 − 월세 − 보증금 기회비용
  * **몇 달치로 보느냐**: 지역별로 다름 (빠른 매도 / 적정 / 높은 호가)
  * **규모에 따른 배수**: 조제료가 클수록 더 쳐주고, 작으면 깎음
  * **결과 형태**: 금액 하나가 아니라 **최소 ~ 최대 범위**
- **각주**: 보증금 기회비용(묶인 돈의 이자) · 회수개월수(월 수익의 몇 배)
- **시각화 가이드**: 곱셈 기호로 연결된 3블록 카드, 하단 범위 바(최소–중간–최대 라벨)

## 섹션 2. 개발 히스토리

### 슬라이드 5: 전체 흐름
- **핵심 메시지**: **정답지 → 계산식 → 보정 → 확장** 순서로 만들었다
- **본문 내용**:
  * **0단계**: 현장의 감을 숫자로 — 20케이스 조사, 오차 측정
  * **1차**: 기본 계산식 — 조사로 숫자 조정, 적중률 68% → 85%
  * **2차**: 튀는 구간 다듬기 — 경계에서 금액이 두 배로 뛰는 문제
  * **3차**: 바깥 데이터 결합 — 공공데이터·지도 + AI 해설
  * **상시화**: 설문 → 저장 → 집계 → **계수 자동 보정**
- **각주**: v1·v2·v3 = 1차·2차·3차 버전 (화면 표기와 동일)
- **시각화 가이드**: 세로 타임라인 5단, 단계별 컬러(회색→앰버→틸→그린→남색)

### 슬라이드 6: 0단계 — 계산식보다 정답지를 먼저
- **핵심 메시지**: 식을 먼저 만들면 **검증할 방법이 영영 생기지 않는다**
- **본문 내용**:
  * **설계**: 가상 **20케이스** = 지역 5권역 × 규모별, 조건은 무작위
  * **의도적 공개**: 계산기가 낸 금액을 **숨기지 않고 함께 제시**
  * **목적**: 정답 수집이 아니라 **오차 측정**
  * **표본**: 1차 2명 **40응답** → 2차 3명 **60응답**
- **각주**: 금액 단위는 만원, 마지막 칸은 조사원이 직접 기입
- **시각화 가이드**: 실제 조사지 표 발췌(케이스 2·7·9·14·17), 마지막 열은 빈칸

### 슬라이드 7: 0단계 결과 — 계산식 선택
- **핵심 메시지**: 일반 상가식은 **평균이 아니라 구조**가 틀렸다
- **본문 내용**:
  * **A안** (매출총이익 × 12개월): 범위 적중 **7/40**
  * **B안** (지역·규모 반영 배수): 범위 적중 **32/40**
  * **작은 약국**: 응답 대비 **3.03배 높게**
  * **보통~큰 약국**: 응답의 **3분의 2 수준**
  * **결론**: 반대 방향 오차 → **어떤 배수로도 동시에 못 맞춤**
- **각주**: 매출총이익(약값 뺀 이익) · "범위 안에 들었다"의 뜻
- **시각화 가이드**: 좌측 막대 차트(7 vs 32), 우측 편향 수치 카드(과대 빨강 / 과소 틸)

### 슬라이드 8: 1차 — 계산식
- **핵심 메시지**: 살아남은 구조를 **5단계 식**으로 구현
- **본문 내용**:
  * **① 한 달에 남는 돈**: 조제 수익 + 일반약 마진 − (월세 + 보증금 기회비용)
  * **② 규모 배수**: 5구간 고정값 (0.50 / 1.00 / 1.15 / 1.25 / 1.35)
  * **③ 3단계 금액**: 지역별 개월수 × 저수익 할인
  * **④ 의사 고령 할인**: 65세 **×0.7** · 75세 **×0.5**
  * **⑤ 보정**: 사용자 의견 ±10% · 설문 ±15%
- **각주**: 저수익 할인의 뜻 · 표의 숫자 = "월 수익의 몇 배"
- **시각화 가이드**: 좌측 5단계 번호 리스트, 우측 지역별 개월수 표

### 슬라이드 9: 1차 검증 — 60응답으로 보정
- **핵심 메시지**: 두 군데만 고쳐 적중률 **68% → 85%**
- **본문 내용**:
  * **발견 ①**: 보통~큰 약국 17건 — 계산기가 **15% 낮음**
  * **발견 ②**: 작은 약국 3건 — 계산기가 **35% 높음**
  * **조치**: 전 지역 개월수 **1.15배** · 작은 약국 배수 **0.88 → 0.50**
  * **결과**: 적중 41/60 → **51/60**
  * **조사원 3**: 9/20 → **18/20**
- **각주**: 막대 수치의 읽는 법 · "적중 51/60"의 뜻
- **시각화 가이드**: 고치기 전/후 그룹 막대(전체·작은·보통~큰), 우측 발견·조치 요약

### 슬라이드 10: 1차 문제 — 절벽
- **핵심 메시지**: 조제료 **1만원** 차이로 권리금이 **2배**가 된다
- **본문 내용**:
  * **999만원**: 배수 0.50 → **9,118만원 ~ 1.49억원**
  * **1,000만원**: 배수 1.00 → **1.83억원 ~ 2.99억원**
  * **경계별 점프**: 1,000만원 **+100%** / 이후 +15% · +9% · +8%
- **시각화 가이드**: 실제 화면 캡처 2단 비교, 하단에 경계별 점프 카드 4장(첫 칸만 빨강)

### 슬라이드 11: 2차 — 완만화 방법 선택
- **핵심 메시지**: 다섯 숫자는 **검증된 자산** — 바꿀 것은 "구간마다 고정"이라는 가정
- **본문 내용**:
  * **안 1 — 구간 세분화**: 튐이 작아질 뿐 **소멸 안 함**
  * **안 2 — 곡선 새로 그리기**: 검증값 소멸 + 20건으로는 **억지로 맞추는 셈**
  * **안 3 — 네 지점 보존, 사이만 직선**: 검증 결과 **100% 보존** → **채택**
- **각주**: 선형보간 · 과적합의 뜻
- **시각화 가이드**: 3개 안 비교표(채택 행 볼드), 하단 다크 박스에 중간값 구하는 식(말로 풀어쓴 형태)

### 슬라이드 12: 2차 — 결과 곡선
- **핵심 메시지**: 네 지점에서 **만나고**, 사이에서만 달라진다
- **본문 내용**:
  * **경계 점프**: +100% → **+0.05%**
  * **나머지 경계**: 모두 +0.01% 이하
  * **동일 조건 999만원**: 1차 9,118만원 → 2차 **1.82억원**
- **시각화 가이드**: 배수 곡선 비교 그래프(1차 계단 앰버 / 2차 직선 틸, 1,000만원 지점 빨강) 전면 배치

### 슬라이드 13: 2차 검증 — 반전
- **핵심 메시지**: **매끄러운 식이 정확한 식은 아니었다**
- **본문 내용**:
  * **1차**: 적중 **51/60** · 작은 약국 **0.99**
  * **2차**: 적중 42/60 · 작은 약국 **0.53**
  * **원인**: 2차는 0~1,000만원을 직선으로 이어 800만원에 배수 **0.90**
  * **충돌**: 1차의 0.50은 **작은 약국 응답으로 직접 맞춘 값**
  * **판단**: 표본 3건 → 결론 불가 → **1차 기본값 유지**
- **각주**: 충돌의 의미 · 표본 30건이 모이면 결정 가능
- **시각화 가이드**: 구간별 그룹 막대(작은 약국 격차를 빨강), 우측에 원인·판단

### 슬라이드 14: 3차 — 입력할 수 없는 데이터
- **핵심 메시지**: 핵심 정보는 **사용자가 모르는 정보**였다
- **본문 내용**:
  * **적용**: 병·의원 수 · 약국 수 · 반경 500m 상가 · 주소→좌표
  * **판정 기준**: 약국 1곳당 병·의원 수를 **전국 평균 1.7곳**과 비교
  * **미적용**: 처방·진료비 통계 — **약국 단위 공개 없음**
  * **부재**: 권리금 **실거래 자료 자체가 없음**
  * **원칙**: 못 받아와도 그 칸만 "미조회" — **계산은 정상**
- **각주**: 데이터를 받아오는 방식(조회 통로)
- **시각화 가이드**: 데이터 소스 표(적용/미적용), 우측 1.7:1 3단계 판정 카드

### 슬라이드 15: 3차 — 화면
- **핵심 메시지**: 받아온 수치로 **사용자 입력까지 검증**한다
- **본문 내용**:
  * **실측**: 강남구 병·의원 **3,119곳** / 약국 **515곳** = **6.1:1**
  * **비교**: 전국 평균 1.7:1 대비 **3.6배**
  * **입력 검증**: 선택한 상권 유형이 실제와 다르면 지적
  * **금액 연결**: 고치면 +10% → **+15%**, 4.07~6.68억 → **4.25~6.99억**
- **각주**: AI가 지적하고 금액까지 다시 보여준다는 설명
- **시각화 가이드**: 화면 캡처 3분할(좌: 산출 / 우상: 실측 / 우하: 입력 검증) + 좌하단 수치 3줄

### 슬라이드 16: 3차 — AI에게 금액은 맡기지 않는다
- **핵심 메시지**: **말로 부탁한 건 깨지고, 형식으로 막은 것만 남았다**
- **본문 내용**:
  * **원칙**: 수치는 프로그램이 확정 → AI는 **해설만**
  * **실패 ①**: 금액이 매번 다름 → **다시 계산 금지** 명시
  * **실패 ②**: 긴 줄글로 회신 → **8개 칸으로 형식 고정**
  * **실패 ③**: 범위를 단일 금액으로 단정 → 범위 기준 지시 삽입
  * **실패 ④**: 검증이 "타당합니다"로 종료 → **보기 중 선택 + 금액 재계산**
  * **실패 ⑤·⑥**: 답변 잘림 → 길이 상한 분리 / 고령 **이중 할인** → 한 곳으로 통일
- **각주**: "창의성 0" 설정의 뜻 · 공통점 한 줄
- **시각화 가이드**: 좌측 다크 카드에 AI 지시문 발췌(한글), 우측 실패→해결 6행 표

### 슬라이드 17: 1차 ~ 3차 종합 비교
- **핵심 메시지**: 세 버전은 **경쟁이 아니라 역할 분담**
- **본문 내용**:
  * **기본 계산**: 1차 = 3차 **같은 계산식** / 2차는 배수 구하는 법만 교체
  * **60건 중 적중**: **51건** · 42건 · 1차와 동일
  * **입력 항목**: 5개 · 5개 · **15개 이상**
  * **바깥 데이터**: 없음 · 없음 · **병·의원 · 약국 · 상가 · AI**
  * **쓰임**: **기본 시세** · 튀는 구간 비교 · **매물 실사·협상 준비**
- **각주**: 3차의 기본 금액이 1차와 같다는 점 (화면에도 환산 줄로 표시)
- **시각화 가이드**: 3열 비교표, 하단에 3차 검증 4축 배지(기본 금액 일치 · 재현성 · 실측 · 고장 대비)

## 섹션 3. 데이터와 API

### 슬라이드 18: 조사 원자료와 재현성
- **핵심 메시지**: 발표의 모든 수치는 **원자료에서 다시 계산된다**
- **본문 내용**:
  * **원자료**: 20케이스 × 3명 = **60응답** (2026-09)
  * **기록 항목**: 조건 · 계산기 제시 금액 · 조사원 응답
  * **재현**: 검증용 계산 파일 하나로 **4개 조합 일괄 출력**
  * **검증 지표**: 범위 적중 · 응답÷계산기 배율 · 케이스별 · 조사원별
- **각주**: 검증용 계산 파일이 무엇인지 · 발표 중 근거 질문 대응법
- **시각화 가이드**: 좌측 원자료 구조 표, 우측 다크 박스에 결과 4줄, 하단에 지표를 넷으로 나눈 이유

### 슬라이드 19: 사용한 데이터와 키 발급
- **핵심 메시지**: **무료 공개 데이터 3종**, 없어도 계산은 된다
- **본문 내용**:
  * **공공데이터포털**: 병의원 찾기 · 약국 찾기 · 상가(상권)정보
  * **카카오 지도**: 주소를 좌표로 / 주소 검색창은 **신청 불필요**
  * **Google AI**: 상권·위험 해설, 입력 검증
  * **주의**: 공공데이터포털은 **"Decoding" 키**를 써야 함
- **각주**: 인증키가 무엇인지 · 키가 없거나 실패할 때의 동작
- **시각화 가이드**: API 3블록 카드(제공처 + 받는 방법), 하단 빨강 경고 스트립

## 섹션 4. 앞으로

### 슬라이드 20: 상시 검증 구조
- **핵심 메시지**: 일회성 조사를 **쓸수록 정확해지는 구조**로
- **본문 내용**:
  * **설문**: 1명당 **6케이스 · 2~3분** · 익명
  * **저장**: 유형 · 지역 · 조사원 · 공개 전 추정액 · 판정 · 조정액
  * **집계 → 반영**: 관리자 화면에서 확인 후 **버튼 한 번**
  * **안전장치**: 유형 4종 분리 · **30건 이상**만 · 조정 폭 **±10~15%**
- **시각화 가이드**: 좌측 4단 흐름(설문→저장→집계→반영), 우측 설문 화면 캡처

### 슬라이드 21: 로드맵
- **핵심 메시지**: 표본을 채우면 **남은 판단이 데이터로 결정**된다
- **본문 내용**:
  * **1단계 (단기)**: 지역별 **30건+** · 지방 중소도시 집중 · **큰 약국 표본 0건** 해소
  * **2단계 (중기)**: 1차/2차 **확정** · 병원 의존도 **숫자로** · 저수익 기준 지역별 분리
  * **3단계 (장기)**: 권리금 **구성 분해** · 매물 비교 · **PDF 리포트** · 시세 흐름
  * **운영**: 계정 전환 · 응답 지연 대응 · **숫자 변경 이력 관리**
- **시각화 가이드**: 3단 수평 카드(단기/중기/장기), 각 카드 하단에 "목표" 한 줄

### 슬라이드 22: 한계와 마무리
- **핵심 메시지**: 실거래 조회가 아니라 **설명 가능한 추정**
- **본문 내용**:
  * **한계 ①**: 공개 실거래 자료 **없음** → 수익 구조 기반 추정
  * **한계 ②**: 실제 거래는 **±30%** 변동
  * **한계 ③**: 조사원 3명·20케이스, **큰 약국 미검증**
  * **가치**: "그냥 그 정도" 대신 **어떻게 나왔는지 설명 가능**
- **시각화 가이드**: 한계 3항목 리스트 + 하단 다크 박스에 마무리 한 줄
