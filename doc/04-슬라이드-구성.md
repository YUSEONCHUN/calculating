## 설계 원칙

| 원칙 | 적용 |
|---|---|
| **10~20분 분량** | 보이는 19장으로 15분. 상세 자료 8장은 PowerPoint **숨김**으로 두고 질문이 나올 때만 번호로 띄움 |
| **주제 전환은 질문으로** | WHY / HOW / SO WHAT / NEXT 전환 장 4개. 각 장에 **"앞에서 본 것 → 지금부터 볼 것"** 을 적어 흐름을 잇는다 |
| **장과 장 사이도 잇는다** | 주제를 넘기는 슬라이드 끝에 `→` 한 줄(bridge)을 둬 다음 장의 첫 문장이 되게 한다 |
| **1장 = 메시지 1개** | 줄글 없이 헤드라인 → 불릿 → 정량 수치 계층 |
| **비개발자 발표자 기준** | 본문은 일상어, 남는 용어는 하단 각주, 27장에 용어표 |

## 전체 지도

`숨김`은 슬라이드쇼에서 건너뛰고, 번호를 눌러 띄웁니다.

| # | 유형 | 헤드라인 | 핵심 | 비고 |
|---|---|---|---|---|
| 1 | 표지 | 약국 권리금 계산기 | 네 부분 구성 · 약 15분 | |
| 2 | **전환 1/4** | **WHY** — 왜 이 계산기를 만들었나 | 앞: (시작) → 지금: 문제와 기존 계산기의 한계 | |
| 3 | 내용 | 가장 큰 금액이 걸린 결정을, 가장 경험 없는 상태에서 | 제시 → 판단 불가 → 감 → 근거 부재 4단 | bridge |
| 4 | 내용 | 약국은 권리금 구성 요소 자체가 다르다 | 일반 상가 vs 약국 비교표 | bridge · 10분 때 생략 |
| 5 | 내용 | 감이 담은 판단을 수식과 숫자로 옮긴다 | 세 요소 곱셈 + 범위 제시 | 각주 2 |
| 6 | **전환 2/4** | **HOW** — 이 숫자들을 어떻게 믿게 만들었나 | 앞: 전용 계산식이 필요한 이유 → 지금: 정답지와 1~3차 | |
| 7 | 내용 | 정답지 → 계산식 → 보정 → 확장 | 5단 타임라인 | bridge · 10분 때 생략 |
| 8 | 차트 | 계산식보다 정답지를 먼저 만들었다 | 조사 설계 + A안 7/40 vs B안 32/40 + 편향 3.03 / 0.67 | bridge · 각주 2 |
| 9 | 내용 | 조사지는 이렇게 생겼다 | 조사지 원본 5행 + 설계·표본 | **숨김** |
| 10 | 차트 | 1차 — 두 군데만 고쳐 적중률 68% → 85% | 고치기 전/후 구간별 막대 + 조사원 3 (9→18) | bridge · 각주 2 |
| 11 | 내용 | 1차 계산식 — 5단계 | 5단계 + 지역별 개월수 표 | **숨김** |

| 13 | 이미지 | 2차 — 네 지점은 두고, 사이만 직선으로 | 배수 곡선 그래프 + 수치 3 | bridge · 10분 때 10초 |
| 14 | 내용 | 2차 — 세 가지 안을 두고 고른 과정 | 3안 비교표 + 중간값 식 | **숨김** |
| 15 | 차트 | **매끄럽게 만들었더니, 오히려 덜 맞았다** | 1차 51/60 vs 2차 42/60 · 작은 약국 0.99 vs 0.53 | ★ 핵심 · bridge · 각주 2 |
| 16 | 이미지 | 3차 — 사용자가 모르는 정보를 대신 가져왔다 | 실측·입력 검증 화면 + 요약 카드 4 | 각주 |
| 17 | 내용 | 3차 — 가져올 수 있는 데이터를 찾은 결과 | 데이터 목록(적용/미적용) + 판정 기준 | **숨김** |

## 디자인 — 사내 템플릿 기준

제공받은 사내 PPT 템플릿(`파워포인트-템플릿-...-1840.pptx`)의 색과 서체를 그대로 가져왔습니다.

| 요소 | 값 | 쓰임 |
|---|---|---|
| 인디고 | `#42469F` | 기본색 · 1차 · 제목 옆 세로 바 · 강조 |
| 네이비 | `#273164` | 표지 · 전환 슬라이드 배경 · 3차 |
| 연인디고 | `#7E86D6` | 2차 · 보조 테두리 |
| 오렌지 | `#FF6600` / `#FF9A4D` | 상시화 · 주의 · 전환 슬라이드의 큰 단어 |
| 레드 | `#E0453F` | 문제 지점 (근거 부재 · 절벽 +100%) |
| 페이지 배경 | `#E9ECF4` | 템플릿의 연보라 톤. 본문 카드는 흰색이라 대비가 산다 |
| 서체 | **맑은 고딕** | 템플릿과 동일. 한글이 의도한 서체로 렌더된다 |

차트 색도 같은 규칙을 따릅니다.

| 차트 | 계열 | 색 |
|---|---|---|
| 8번 — 계산식 선택 | A안 (탈락) / B안 (채택) | 레드 `#E0453F` / 인디고 `#42469F` |
| 10번 — 1차 보정 | 고치기 전 / 고친 후 | 회색 `#8A90A8` / 인디고 `#42469F` |
| 15번 — 1차 vs 2차 | 1차 (기본값) / 2차 (비교용) | 인디고 `#42469F` / 오렌지 `#FF6600` |

> 2차는 틀린 게 아니라 "덜 맞은" 쪽이라 레드가 아니라 오렌지를 씁니다. 레드는 탈락한 A안과 절벽 지점에만 씁니다.

템플릿에서 가져온 구성 요소도 있습니다.

- **이중 테두리 카드** — 카드 뒤에 살짝 비켜 놓은 외곽선 (5번 공식 블록, 25번 로드맵 카드)
- **제목 옆 세로 인디고 바** — 모든 본문 슬라이드 좌측 여백에 고정
- **흰 액자** — 화면 캡처가 연보라 배경 위에서 떠 보이지 않도록 흰 카드로 감쌈

## 용어를 다루는 방식

| 전 | 후 |
|---|---|
| 회수개월수 | **몇 달치로 보느냐** |
| 조제료 규모 계수 | **규모에 따른 배수** |
| 선형보간 | **네 지점은 두고 사이만 직선으로** |
| temperature 0 | **같은 질문에 늘 같은 답을 하도록 고정** |
| responseSchema 8필드 | **답변을 8개 칸으로 나눠 받도록 형식 고정** |
| 과적합 | **20건에 억지로 맞추는 셈** |
| v1 · v2 · v3 | **1차 · 2차 · 3차** (화면 표기는 그대로라 각주로 연결) |

각주는 슬라이드 하단 구분선 아래 회색 10.5pt로 두 줄 이내. 발표 중 질문이 나오면 **그대로 읽으면 답이 되도록** 썼습니다.
