# 권리금 도구 (forkAddon)

데일리팜 약국 툴에서 **권리금 관련 기능만 분리**한 독립 프로젝트입니다. Docker 로 바로 띄울 수 있습니다.

## 빠르게 띄우기

```bash
cp .env.example .env     # 포트·키 확인 후 수정
docker compose up -d --build
```

- 웹: http://localhost:8090 (`.env` 의 `WEB_PORT`)
- DB: localhost:3318 (`.env` 의 `DB_PORT_HOST`) — 컨테이너 내부에서는 `db:3306`
- 스키마는 DB 최초 기동 시 `schema.sql` 이 자동 적용됩니다.

**로그인이 없습니다.** 권리금 도구는 모두 공개라 바로 쓸 수 있고,
관리자 페이지만 `.env` 의 `DASHBOARD_PASSWORD` 로 보호됩니다 (인증하면 사이드바에 관리자 메뉴가 나타납니다).

## 들어 있는 도구

| 페이지 | 설명 |
|---|---|
| goodwill.php | 권리금 시세 — 실거래 회수배수 모델로 최소~최대 범위 산정, 범위 내 위치 판단 체크리스트 |
| premium.php | 권리금 계산 — 시세에 상권·병원 의존도·임대차 조건을 반영한 정밀 산정 + 개국 자금 계획 (AI 분석) |
| goodwill_parts.php | 권리금 구성 — 총액을 바닥·영업·시설(재고 포함)로 분해 |
| listings.php | 매물 비교 — 받은 매물을 같은 모델로 평가·비교, 반경 500m 약국 조회 |
| goodwill_survey.php | 적정성 설문 — 조사원 배포용, 응답이 쌓이면 지역 보정에 반영 |
| premium_curve.php / goodwill_curve.php | 곡선형 보간 비교용 |

전부 로그인 없이 접근합니다. 관리자(비밀번호 보호): 참고 데이터(지역 회수개월수·규모 계수) · 가중치 · 설문 집계(원클릭 보정) · 수집 데이터

## 계산 모델

권리금 = **월 환산수익 × 지역 회수개월수 × 조제료 규모 계수**, 여기에 저수익 임계 할인과
의사 고령 할인, 지역 피드백·설문 보정을 적용합니다. 핵심 구현은 `src/config.php` 의 `gwBaseQuote()` 한 곳에 있고
시세·계산·구성·매물 비교가 모두 이 함수(또는 동일 계산의 JS 포트)를 씁니다.

기준값은 2026-09 적정성 조사(조사원 3명 × 20케이스 = 60응답)를 반영한 상태입니다
— 지역 회수개월수 전 지역 ×1.15, 조제료 1,000만원 미만 규모 계수 0.50.

## API 키 (선택)

`.env` 에 넣으면 해당 기능이 켜집니다. 없어도 권리금 계산 자체는 동작합니다.

- `GEMINI_API_KEY` — 권리금 계산의 AI 상권·리스크 분석
- `KAKAO_REST_KEY` — 매물 비교의 반경 500m 약국 조회, 주소 좌표 변환
- `DATA_GO_KR_KEY` — 병·의원/약국 실측 조회

## 접근 제어

원본의 회원 등급 체계(로그인·승인)는 걷어냈습니다. `src/auth.php` 가 호출부 호환용 껍데기로 남아
`authGuard()` 는 항상 통과시키고 `authLevel()` 은 관리자 비밀번호 인증 여부만 반환합니다.
다시 로그인 기반으로 돌리려면 이 파일만 교체하면 됩니다.

지역 파트너(컨설팅·중개사) 소개 기능도 제거했습니다 — 관련 페이지·테이블 모두 없습니다.

## 운영 메모

- 소스는 `./src` 가 컨테이너에 마운트되어 **수정하면 새로고침만으로 반영**됩니다. 이미지에 굽고 싶으면 compose 의 volumes 에서 `./src` 줄을 빼세요.
- `.env` · `.sql` · `.md` 는 Apache 설정으로 웹 노출이 차단됩니다.
- PHP 오류는 화면에 표시하지 않고 컨테이너 로그로 보냅니다: `docker compose logs -f web`
